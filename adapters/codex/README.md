# Codex Adapter: video-intake-knowledge

Integra la skill universal `video-intake-knowledge` en entornos **OpenAI Codex** y **Codex CLI**.

## Instalación

```bash
bash adapters/codex/install.sh
```

Instala la definición de la skill en `~/.codex/skills/video-intake/SKILL.md`.

## Desinstalación

```bash
bash adapters/codex/uninstall.sh
```
