# Code of Conduct de video-intake-knowledge

## Nuestro compromiso

Nos comprometemos a proporcionar un espacio seguro, inclusivo y respetuoso
para todos los colaboradores, independientemente de:

- Edad, cuerpo, discapacidad visible o no visible.
- Características raciales, étnicas o de nacionalidad.
- Identidad de género, expresión de género, orientación sexual.
- Experiencia, nivel de conocimiento, habilidades técnicas.
- Antecedentes educativos, socioeconómicos, culturales o religiosos.
- Ideología política, afiliación sindical o cualquier otro aspecto personal.

## Estándares esperados

### Comportamientos positivos

- Demuestra empatía y amabilidad hacia los demás.
- Respeta opiniones, perspectivas y experiencias diferentes.
- Da y recibe feedback constructivo.
- Acepta responsabilidad y disculpa cuando sea necesario.
- Se centra en lo que es mejor para la comunidad y el proyecto.

### Comportamientos inaceptables

- Ataques verbales, amenazas, insultos o sarcasmo hostil.
- Discriminación, acoso o exclusión basada en cualquiera de las características
  listadas arriba.
- Publicación de información privada de otros (direcciones, correos, etc.)
  sin permiso explícito.
- Acoso sexual, lenguaje sexualizado no deseado, comentarios sobre apariencia.
- Trolling, provocación innecesaria, o comportamiento que interrumpa
  deliberadamente discusiones o reuniones.
- Uso de lenguaje que socave la dignidad de personas o grupos.

## Alcance

Este código de conducta aplica a todas las interacciones relacionadas con el
proyecto:

- Repositorio GitHub (issues, pull requests, discusión, comentarios).
- Canales de comunicación del proyecto (email, chat, etc.).
- Reuniones, eventos, conferencias o actividades organizadas por el proyecto.
- Cualquier otro espacio donde se deba tu participación al proyecto.

## Haciendo cumplir el código de conducta

### Reportar incumplimientos

Si experimentas o presupostas un incumplimiento del código de conducta, puedes
reportarlo contactando al equipo de maintainers:

- Email: `coc@aibos.local` (si está configurado).
- Issue privado en GitHub (si está disponible).
- Cualquier método de contacto listado en `CONTRIBUTING.md`.

Todos los reports serán revisados y investigados de forma confidencial.

### Qué pasa tras un reporte

1. El equipo de maintainers revisa el reporte.
2. Si el incidente se confirma, se toman medidas apropiadas.
3. Se informa al reporter sobre el resultado (sin revelar detalles privados
   del infractor, salvo lo necesario).

Las medidas pueden incluir, según se requiera:

- Solicitar disculpa.
- Advertencia formal.
- Suspención temporaria de participación.
- Ban permanente del projecto.

## Atribución

Este código de conducta se basa en el
[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html),
uno de los códigos de conducta más usados en proyectos de código abierto.

Para preguntas sobre este código de conducta, contacta a los maintainers.
