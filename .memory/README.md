# Video Intake Knowledge - Memory Bank Configuration

This directory contains the dedicated memory bank for the video-intake-knowledge project.
It is independent from AibOS/AiboT and maintained separately.

## Structure

- `bank/` - Persistent memory storage for project context
- `scripts/` - Memory management scripts

## Usage

The memory bank stores:
- Project decisions and architecture choices
- Configuration history
- Integration notes with Hermes Agent
- Known issues and resolutions

## Independence

This memory bank is completely independent from:
- AibOS core memory
- AiboT memory
- Any other project's memory

This ensures the video-intake-knowledge project maintains its own context
without interference from other systems.
